About PrismCC Reference GitHub

PrismCC

PrismCC is the in-OS subset C compiler that turns source files into BCVM bytecode packaged as Prism app images.

Open the compiler reference for the supported language features, built-ins, limits, and shell workflow.

Open PrismCC Reference →

What It Supports

Functions, overloads, int and string values, fixed-size int[N] arrays, control flow, arithmetic, comparisons, string helpers, console I/O, and file I/O.

Shell Workflow

Compile with cc <input.c> <output.app> inside PrismOS, then run the app with app-run.
